# Инструкция по установке и запуску бота

## 1. Подготовка системы
```bash
# Обновление пакетов
apt update
apt install python3-pip

# Установка необходимых Python библиотек
pip3 install aiogram aiohttp
```

## 2. Создание структуры проекта
```bash
# Создаем директорию для бота в /opt (стандартное место для доп. программ)
mkdir -p /opt/telegram_bot
cd /opt/telegram_bot

# Создаем директорию для логов
mkdir logs
```

## 3. Настройка файлов проекта

### Создание файла с переменными окружения:
```bash
# Создаем файл .env
echo "BOT_TOKEN=ваш_токен_от_BotFather" > /opt/telegram_bot/.env
```

### Создание файла бота:
```bash
# Создаем файл bot.py
nano /opt/telegram_bot/bot.py
# Вставьте код бота из предыдущего сообщения
```

## 4. Запуск бота
```bash
# Переходим в директорию бота
cd /opt/telegram_bot

# Запускаем бота в фоновом режиме с логированием
nohup python3 bot.py > logs/bot.log 2>&1 &
```

## 5. Управление ботом

### Проверка работы:
```bash
# Просмотр логов в реальном времени
tail -f logs/bot.log

# Проверка что процесс запущен
ps aux | grep "python3 bot.py"
```

### Управление процессом:
```bash
# Найти PID бота
ps aux | grep "python3 bot.py"

# Остановить бота
kill <PID>

# Перезапустить бота
cd /opt/telegram_bot
nohup python3 bot.py > logs/bot.log 2>&1 &
```

## Автозапуск после перезагрузки

Создайте скрипт автозапуска:
```bash
# Создаем скрипт
cat > /opt/telegram_bot/start_bot.sh << 'EOF'
#!/bin/bash
cd /opt/telegram_bot
nohup python3 bot.py > logs/bot.log 2>&1 &
EOF

# Делаем скрипт исполняемым
chmod +x /opt/telegram_bot/start_bot.sh

# Добавляем в crontab для автозапуска
(crontab -l 2>/dev/null; echo "@reboot /opt/telegram_bot/start_bot.sh") | crontab -
```

## Преимущества этой структуры:

1. **Организация**: 
   - Все файлы бота находятся в одном месте (/opt/telegram_bot)
   - Логи хранятся в отдельной директории
   - Скрипт автозапуска в той же директории

2. **Безопасность**:
   - Изолированная директория для бота
   - Отдельная директория для логов
   - Легко делать бэкап всего бота

3. **Удобство обслуживания**:
   - Простой доступ к логам
   - Автозапуск после перезагрузки
   - Простое управление процессом

4. **Масштабируемость**:
   - Легко добавить новые функции
   - Просто обновлять код
   - Можно добавлять дополнительные скрипты
